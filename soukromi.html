Zásady ochrany soukromí

Klicenka je soukromý nástroj, který používá jen jeho vlastník se svými vlastními účty Google.

  • Přístup ke Gmailu (čtení, štítky, koncepty) se používá jen v počítači vlastníka. Nástroj nemá žádný server a data nikam neodesílá.
  • Přihlašovací tokeny zůstávají uložené v počítači vlastníka. Nikomu se nepředávají, neprodávají ani se nepoužívají k reklamě.
  • Použití dat získaných z Google API odpovídá zásadám Google API Services User Data Policy včetně požadavků Limited Use.
  • Přístup lze kdykoli zrušit na myaccount.google.com/permissions.
